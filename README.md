# River & Roast Coffee Co. — Static website

This version uses plain HTML, CSS, and JavaScript. No npm install or build is required.

## Preview
Open index.html in your browser. Photos load from Unsplash and require an internet connection.

## Publish on GitHub Pages
1. Extract this ZIP.
2. Upload the extracted files to the root of your GitHub repository (not the ZIP or an enclosing folder). Keep index.html, styles.css, script.js and favicon.svg together. Include .nojekyll if using Git to upload.
3. Commit the files to the main branch.
4. In your repository, open Settings → Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select main and /(root), then Save.
7. Once deployment finishes, use the site link displayed on the Pages settings page.

Documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Included behavior
Responsive mobile navigation, native expandable FAQs, anchor links, and contact-form preview. The contact form does not send or store messages. Ordering, business contact details, maps, and reviews retain the original placeholders. Photos are illustrative external Unsplash images.
